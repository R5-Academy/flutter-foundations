# Escopo de Contexto

Código da aula **Escopo de Contexto** (BuildContext) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_escopo_context_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_escopo_context/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 05-02-escopo-de-contexto --single-branch https://github.com/R5-Academy/flutter-foundations.git 05-02-escopo-de-contexto
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/05-02-escopo-de-contexto.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
