# Assets e Fontes

Código da aula **Assets e Fontes** (Anatomia do Projeto) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `projeto_assets_exemplo_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `projeto_assets_exemplo/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 01-04-assets-e-fontes --single-branch https://github.com/R5-Academy/flutter-foundations.git 01-04-assets-e-fontes
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/01-04-assets-e-fontes.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
