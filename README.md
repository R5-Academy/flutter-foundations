# initState

Código da aula **initState** (Ciclo de Vida) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_init_state_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_init_state/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 06-03-initstate --single-branch https://github.com/R5-Academy/flutter-foundations.git 06-03-initstate
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/06-03-initstate.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
