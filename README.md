# Skill Layout Creator

Código da aula **Skill Layout Creator** (Prática e IA) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `.claude` — material usado na aula.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 03-02-skill-layout-creator --single-branch https://github.com/R5-Academy/flutter-foundations.git 03-02-skill-layout-creator
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/03-02-skill-layout-creator.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
