# Resolução

Código da aula **Resolução** (Prática e IA) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `primeiro_layout_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `primeiro_layout/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 03-04-resolucao --single-branch https://github.com/R5-Academy/flutter-foundations.git 03-04-resolucao
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/03-04-resolucao.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
