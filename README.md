# dispose

Código da aula **dispose** (Ciclo de Vida) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_dispose_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_dispose/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 06-08-dispose --single-branch https://github.com/R5-Academy/flutter-foundations.git 06-08-dispose
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/06-08-dispose.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
