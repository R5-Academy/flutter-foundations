## Como baixar

Só esta aula, com git:

```bash
git clone -b 06-04-apos-o-primeiro-frame-addpostframecallback --single-branch https://github.com/R5-Academy/flutter-foundations.git 06-04-apos-o-primeiro-frame-addpostframecallback
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/06-04-apos-o-primeiro-frame-addpostframecallback.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.
