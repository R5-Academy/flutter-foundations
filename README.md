# LocalKey vs GlobalKey

Código da aula **LocalKey vs GlobalKey** (Keys) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_localkey_globalkey_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_localkey_globalkey/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 07-03-localkey-vs-globalkey --single-branch https://github.com/R5-Academy/flutter-foundations.git 07-03-localkey-vs-globalkey
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/07-03-localkey-vs-globalkey.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
