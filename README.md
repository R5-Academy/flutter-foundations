# MediaQuery: Conhecendo a Tela

Código da aula **MediaQuery: Conhecendo a Tela** (O Ambiente do App) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `mediaquery_exemplos_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `mediaquery_exemplos/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 04-02-mediaquery-conhecendo-a-tela --single-branch https://github.com/R5-Academy/flutter-foundations.git 04-02-mediaquery-conhecendo-a-tela
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/04-02-mediaquery-conhecendo-a-tela.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
