# Flutter Foundations

Código do curso **Flutter Foundations** da R5 Flutter Academy.

Este repositório reúne os projetos Flutter usados nas aulas do curso. Para cada
aula há o projeto no **ponto de partida**, para você acompanhar o vídeo
escrevendo o código junto, e o projeto **como ficou ao fim da gravação**, para
conferir o resultado.

O link para baixar o código de cada aula está na descrição do vídeo dela.

## O que o curso cobre

- Anatomia do Projeto
- Fundamentos dos Widgets
- Prática e IA
- O Ambiente do App
- BuildContext
- Ciclo de Vida
- Keys
- Projeto Prático - Perfil de Usuário
- Resolução do Projeto

## Como rodar um projeto

```bash
cd <pasta-do-projeto>
flutter pub get
flutter run
```
