# Composição de Widgets

Código da aula **Composição de Widgets** (Fundamentos dos Widgets) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 02-04-composicao-de-widgets --single-branch https://github.com/R5-Academy/flutter-foundations.git 02-04-composicao-de-widgets
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/02-04-composicao-de-widgets.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
