# StatelessWidget

Código da aula **StatelessWidget** (Fundamentos dos Widgets) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_stateless_widget_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_stateless_widget/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 02-02-statelesswidget --single-branch https://github.com/R5-Academy/flutter-foundations.git 02-02-statelesswidget
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/02-02-statelesswidget.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
