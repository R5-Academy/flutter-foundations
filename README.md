# Desafio de tela

Código da aula **Desafio de tela** (Prática e IA) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `app.png` — material usado na aula.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 03-03-desafio-de-tela --single-branch https://github.com/R5-Academy/flutter-foundations.git 03-03-desafio-de-tela
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/03-03-desafio-de-tela.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
