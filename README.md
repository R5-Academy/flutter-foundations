# Tema: Estilizando seu App

Código da aula **Tema: Estilizando seu App** (O Ambiente do App) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `estilizando_app_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `estilizando_app/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 04-01-tema-estilizando-seu-app --single-branch https://github.com/R5-Academy/flutter-foundations.git 04-01-tema-estilizando-seu-app
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/04-01-tema-estilizando-seu-app.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
