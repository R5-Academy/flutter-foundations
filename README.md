# ValueKey

Código da aula **ValueKey** (Keys) do curso **Flutter Foundations** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_valuekey_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_valuekey/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 07-04-valuekey --single-branch https://github.com/R5-Academy/flutter-foundations.git 07-04-valuekey
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/07-04-valuekey.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-foundations>
