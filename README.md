## Como baixar

Só esta aula, com git:

```bash
git clone -b 01-01-criando-um-projeto-com-flutter-create --single-branch https://github.com/R5-Academy/flutter-foundations.git 01-01-criando-um-projeto-com-flutter-create
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-foundations/archive/refs/heads/01-01-criando-um-projeto-com-flutter-create.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.
